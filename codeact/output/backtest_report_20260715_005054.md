## 📖 指标说明

| 指标 | 含义 | 评价标准 |
|---|---|---|
| **Fitness** | 综合评分 = Sharpe × √|Returns| / max(Turnover, 0.125) | ≥ 1.0 为优秀 |
| **Sharpe** | 夏普比率 = (年化收益 - 无风险利率) / 年化波动率 | ≥ 1.25 为优秀 |
| **年化收益** | 多空组合的年化复合收益率 | 越高越好 |
| **最大回撤** | 净值从峰值到谷底的最大跌幅 | 越小越好，< 20% 为可接受 |
| **日换手率** | 每日调仓比例 | 1%~70% 为合理区间 |
| **IC** | 信息系数 = 因子值与未来收益的相关系数 | > 0.05 有信息含量 |
| **Rank IC** | 秩信息系数 = 因子排名与收益排名的相关系数 | > 0.05 有信息含量 |
| **年化ICIR** | IC的均值/标准差 × √252 | > 2.0 为稳定有效 |

## 🔧 回测框架说明

本框架对标 WorldQuant BRAIN 平台的 Alpha 因子研究范式：

1. **因子库**: `alpha_library.py` - 27个经典因子，覆盖5大类别
2. **数据层**: `DataLoader` - 支持模拟数据和 akshare 真实数据
3. **因子预处理**: MAD去极值 + Z-score标准化
4. **回测方法**: 分位数多空组合（Top 10% - Bottom 10%），每日调仓，等权配置
5. **评估指标**: 8大核心指标 + 分层收益检验
6. **Fitness公式**: `Sharpe × sqrt(|Returns|) / max(Turnover, 0.125)`
