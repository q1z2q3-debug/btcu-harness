# WQB变化率跃迁因子批量项目（2026-07-22）
## 项目背景
之前开发的高Sharpe组合因子combo_d10_vol120_w8020 Sharpe=2.24、Fitness=1.34，完全满足因子表现要求，但因混入120日波动率这类极慢变化的因子，导致SELF_CORRELATION高达0.97，远高于WQB平台提交检查0.7的阈值，提交被拒。原有局部微调权重、缩短波动率周期的思路属于局部优化，无法从根本上解决自相关性过高问题，因此从因子设计逻辑层面突破。
## 核心设计思路
放弃在现有因子加权调参的小范围内打转，将所有因子的信号从「水平值」替换为「变化率（一阶差分）」，让信号天然具备更高的变化频率，直接将自相关性压到0.7阈值以下，同时尽可能保留收益预测能力。
## 28个全新因子分7个逻辑方向
| 方向 | 核心逻辑 | 因子数量 |
|------|----------|----------|
| 动量加速度 | 收益/成交量的变化率，不是买最强的而是买变强最快的 | 5 |
| 条件/事件驱动 | 极端行情才出信号，平时躺平，天然低自相关 | 5 |
| 截面排名变化率 | 截面排名的变化量，比静态排名灵敏得多 | 4 |
| 非线性组合 | 乘法/除法/多空相减结构，不是简单的线性加权求和 | 4 |
| 隔夜日内变化率 | alpha_021隔夜减日内逻辑的高阶导数版本 | 5 |
| 量价背离加速度 | 量价背离指标的二阶变化率 | 2 |
| 混合创新 | 跨维度交叉组合的全新逻辑 | 3 |
## 当前状态
28个因子已全部提交回测，提交间隔严格设置为40秒避免429限流，正在批量等待回测结果。筛选标准：Sharpe≥1.25、Fitness≥1.0、SELF_CORRELATION≤0.7，目标产出首个通过WQB平台全部8项提交检查的可正式发布Alpha因子。
