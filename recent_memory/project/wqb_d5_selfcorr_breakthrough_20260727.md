# WQB d5自相关低谷突破项目 回测结果报告（2026-07-27）

## 项目目标
基于此前验证的alpha_021_d5自相关仅0.5838的低谷发现，通过添加1-2%微量vol20权重提升Fitness，同时保持自相关≤0.7，找到同时满足SelfCorr≤0.7且Fitness≥1.0的因子并正式发布。

## 核心结论
1. **decay=15配置缺陷**：当全局设置decay=15时，vol20信号被15日线性平滑完全稀释，d5+vol20组合自相关高达0.98，vol20几乎完全不起作用。
2. **decay=0时的基线自相关上限**：将衰减设置为0后，d5自身的基线自相关约为0.71，加入0.5%-2%权重的vol20完全无法将自相关降到0.7以下，权重调整对自相关的影响极小。
3. **无符合发布条件因子**：本次全部6个测试因子中，2个因子自相关达标（<0.7），但均不满足Fitness≥1.0的要求，最终无因子通过发布阈值，正式提交数量为0。
