# BTCU Harness: 基于平衡三进制认知单元的智能体认知驾驭架构

## Balanced Ternary Cognitive Unit Harness: A Cognitive Architecture for LLM Agents

**版本：v0.2**
**状态：架构设计完成，代码实现验证通过**

---

## 摘要

BTCU Harness 是一个以三态集合 {-1, 0, +1} 为最小认知基元，以 19683 离散认知空间为核心，面向大语言模型（LLM）与智能体（Agent）的认知驾驭架构。该架构通过三态基元、柔性维度、状态编码、记忆生态、决策路径生成与认知内化机制，为智能体建立可解释、可追踪、可演化的认知基础系统。BTCU Harness 不替代大模型，而是作为大模型与 Agent 之间的结构化认知层，逐步实现从"高频调用大模型"到"内部认知自主"的演进。本文提出该架构的理论基础、系统设计、实现方案与初步验证结果。

**关键词**：平衡三进制、认知架构、智能体、大语言模型、三值逻辑、记忆生态、第三选择

## 1 引言

### 1.1 背景与问题

当前大语言模型（LLM）驱动的 Agent 系统虽然能力强大，但在认知层面存在以下结构性问题：

| 问题 | 表现 |
|------|------|
| 状态不可解释 | 连续向量缺乏明确认知语义 |
| 记忆静态化 | 记忆是存储检索，不是生态演化 |
| 决策黑箱化 | 依赖概率或规则，难以追踪推理路径 |
| 不确定性不足 | 无法显式表示未知、转化与矛盾 |
| 长期依赖大模型 | 每次复杂推理都需高成本调用 |
| 人格不稳定 | 缺少长期稳定的认知重心 |

这些问题的共同根源在于：当前 Agent 的认知框架是**隐式二值的**——激活或抑制、做或不做、安全或危险——缺乏表达"转化"和"第三选择"的内禀能力。

### 1.2 平衡三进制的启示

平衡三进制（Balanced Ternary）以 {-1, 0, +1} 为基本数字，具有天然对称性：取反是零成本操作（YIN ↔ YANG, VOID 不变）。苏联 Setun 计算机（1958）曾基于此设计，虽因工程生态原因未普及，但其数学优雅性已被 Shannon 等学者认可。

更重要的是，平衡三进制与中国哲学的结构对应：

- **阴阳**对应 {-1, +1}——对立的两极
- **空/和**对应 {0}——不是空缺，而是转化的枢纽，是"易"（变化本身）的具象化
- **-1 + 1 = 0** 对应"阴阳交冲归空"——对立交互回归创造潜能

这一结构也对应黑格尔辩证法的"正-反-合"和佛法的"缘起论"（因-缘-果中的"缘"即为转化条件）。

### 1.3 本文贡献

本文提出 BTCU Harness 架构，主要贡献包括：

1. **三态认知基元**：将 {-1, 0, +1} 定义为 Agent 认知的基本单元，其中 0（空）不是"不知道"而是"创造与转化的入口"
2. **19683 认知状态空间**：九维三元向量构成 3^9 = 19683 个离散认知状态，提供有限、可枚举、可导航的认知空间
3. **涌现式语义**：状态语义不预设，通过 Agent 实践自然涌现，类似《易经》卦象的千年积累
4. **记忆生态**：记忆不是静态存储而是动态生态，包含状态共振、空性悬置、认知节气涌现
5. **第三选择机制**：二元冲突时不选 A 或 B，而是通过空态生成超越性的第三选择
6. **三阶段成长模型**：从学校（LLM 主导）到内化（模式匹配）到毕业（自主推理）的成本递减路径

## 2 理论基础

### 2.1 三态基元

系统唯一封闭的认知基元定义为：

$$\Sigma = \{-1, 0, +1\}$$

| 值 | 名称 | 语义 |
|----|------|------|
| -1 | 阴（YIN） | 否定、收缩、抑制、回退 |
| 0 | 空（VOID） | 转化、创造、等待、悬置 |
| +1 | 阳（YANG） | 肯定、扩张、激活、前进 |

**核心公理**：

$$-1 + 1 = 0$$

表示对立认知状态的交互进入空态。空态不是"无"，而是"无固定自性，故一切皆可能"——所有态的潜态。

**对称性**：取反操作 $neg(x) = -x$ 是零成本的恒等变换。YANG → YIN, YIN → YANG, VOID → VOID。这意味着否定在认知中不需要额外计算——它是数制内置的属性。

### 2.2 与三值逻辑的关系

BTCU 的三态基元与经典三值逻辑系统有对应关系：

- **Kleene 三值逻辑**：{True, Unknown, False} 对应 {+1, 0, -1}，其中 Unknown 是认知不充分
- **Łukasiewicz 三值逻辑**：{1, 1/2, 0} 对应 {+1, 0, -1}，其中 1/2 是中间值
- **BTCU 的区别**：0 不是"介于真假之间"的中间值，而是**主动的转化态**——是"让阴变为阳、阳变为阴的力量"

### 2.3 与《易经》的结构对应

| 易经 | BTCU | 规模 |
|------|------|------|
| 阴/阳（2） | 阴/空/阳（3） | 基本单元 |
| 六爻（6维） | 九维（9维） | 维度 |
| 2^6 = 64 卦 | 3^9 = 19683 状态 | 状态空间 |
| 固定六爻 | 柔性九维 | 适配性 |
| 卦辞爻辞 | 涌现记忆 | 经验积累 |

BTCU 的关键超越在于：(1) "空"态的存在使变化本身成为内禀能力；(2) 柔性维度允许跨领域适配；(3) 19683 的状态空间比 64 卦大 307 倍。

### 2.4 信息论优势

在所有整数基数的进位制中，e ≈ 2.718 是最高效的基数，3 是最接近 e 的整数。平衡三进制在此基础上叠加了对称性优势：

- 每个数位携带 $\log_2 3 \approx 1.585$ 比特信息量
- 比二进制多约 58%，且无需符号位
- 19683 个状态仅需 9 个三元维度即可表达

## 3 系统架构

### 3.1 总体架构

```
BTCU Harness
├── 认知基元层 (core)         三态定义与基本运算
├── 状态空间层 (core)         19683 编码、距离、拓扑
├── 认知映射层 (mapping)      输入到九维三态的投影
├── 记忆生态层 (memory)       轨迹、共振、悬置、抑制
├── 决策行动层 (decision)     路径生成、第三选择
├── LLM协同层 (llm)           大模型作为顾问与生成引擎
└── 主Agent (agent)           整合所有层的认知循环
```

### 3.2 认知基元层

**Trit 类**：封装 {-1, 0, +1} 的所有运算，包括取反（negate）、加法（公理实现）、乘法、编码/解码。

**核心运算**：
- 取反：$neg(x) = -x$，零成本对称翻转
- 加法：$-1 + 1 = 0$（公理），其余按平衡三进制规则
- 编码：$encode(x) = x + 1$，将 {-1, 0, 1} 映射到 {0, 1, 2}

### 3.3 状态空间层

**CognitiveState 类**：九维三元向量，每个维度是一个 Trit。

$$s = (d_8, d_7, \dots, d_0), \quad d_i \in \{-1, 0, +1\}$$

**编码**：

$$\text{Index}(s) = \sum_{i=0}^{8} (d_i + 1) \cdot 3^i$$

索引范围：$0 \leq \text{Index}(s) \leq 19682$

**特殊状态**：
- 状态 0：全阴（极否）
- 状态 9841：全空（无极，创造潜能）
- 状态 19682：全阳（极泰）

**CognitiveSpace 类**：提供状态空间的拓扑操作，包括距离计算、相邻态发现、路径查找、取反态（错卦操作）。

**关键性质**：从全阴到全阳的任何路径都必须经过空态区域——不存在从极端否定直接跳到极端肯定而不经过转化的路径。

### 3.4 认知映射层

**DimensionAdapter**：新项目启动时，通过 LLM 分析项目领域，适配出最合适的九个维度。适配完成后锁定，不再改变。

**InputProjector**：将自然语言输入投影到九维三元向量。投影方式随成长阶段变化：
- 学校阶段：LLM 评估每个维度
- 内化阶段：模式匹配，LLM 仅处理新输入
- 毕业阶段：主要自主投影，LLM 仅用于真正未知的输入

### 3.5 记忆生态层

**StateMemory**：19683 个"房间"，每个房间存储对应状态的积累经验——访问记录、决策结果、提炼洞见、共振链接、激活水平。

**TransitionMemory**：状态间的"走廊"，记录转化经验——哪些路径反复出现、哪些通向成功（美德）、哪些通向失败（陷阱）。

**MemoryEcology**：统一状态记忆和转化记忆的生态系统，包含：
- **状态共振**：访问一个状态时自动激活相关状态
- **空性悬置**：遗忘是抑制而非删除，记忆衰减但可重新激活
- **认知节气**：从重复模式中涌现的规律（吸引子、美德、陷阱、盲区、共振）
- **记忆传承**：导出/导入整个认知经验

### 3.6 决策行动层

**DecisionPathfinder**：决策不是"选择选项"，而是"生成状态迁移路径"——从当前状态到目标状态的认知路径，每一步是一个维度的微调。路径查找使用贪心算法，并结合记忆中的美德（推荐路径）和陷阱（警告路径）。

**ThirdChoiceGenerator**：当检测到二元冲突时：
1. 分析两个状态的冲突维度
2. 保留一致维度
3. 将冲突维度置空（进入创造潜能）
4. 生成超越对立的第三选择

第三选择不是折中（不是 A 和 B 的平均），而是选择性置空——在一致的领域保持，在冲突的领域开放。

### 3.7 LLM 协同层

**LLMBridge**：统一的大模型接口，支持 API 和回调两种模式。LLM 在系统中的角色随成长阶段递减：

- 学校阶段：维度适配 + 输入投影 + 推理建议
- 内化阶段：仅处理模式匹配失败的新输入
- 毕业阶段：仅作为未知领域的顾问

**成本模型**：
- 传统 Agent：$C \propto N_{call}$（每次推理都调 LLM）
- BTCU 毕业：$C \propto N_{unknown}$（仅在认知盲区调 LLM）

## 5 核心突破

### 5.1 空态作为创造中枢

当前所有 Agent 框架的"0"态都是被动的——表示"无信号"或"不确定"。BTCU 的"空"态是主动的——它是转化的入口、第三选择的生成器、认知从阴到阳的必经之路。

### 5.2 记忆从存储到生态

当前 Agent 的记忆是向量数据库——存一条 embedding，查时算余弦距离。BTCU 的记忆是生态——有共振（状态间互相激活）、有节气（模式涌现）、有传承（经验可导出导入）、有抑制（遗忘不删除）。

### 5.3 决策从选择到生成路径

当前 Agent 决策是"给定选项集，选最优"。BTCU 决策是"从当前状态生成到达目标状态的认知迁移路径"。选项不是预设的，是路径上自然产生的。

### 5.4 成本从持续调用到认知内化

当前 Agent 每次推理都调 LLM。BTCU 通过三阶段成长，逐步将认知能力内化到 19683 空间的记忆中，最终仅在认知盲区调用 LLM。

## 6 讨论与未来工作

### 6.1 NLP 自我层

未来将引入 NLP 自我层——使命、价值观、身份、信念等作为认知空间的"吸引子"。Agent 的日常状态围绕吸引子波动，形成稳定的人格。

### 6.2 认知节气涌现

当前实现了基本的模式发现（吸引子、美德、陷阱、盲区）。未来将深化为"认知节气"——在 19683 空间中发现类似二十四节气的周期性认知规律。

### 6.3 多 Agent 协作

三态基元天然支持多 Agent 协作：+1（协同）、-1（对抗）、0（独立）。两个 Agent 可以共享认知空间，在共振态下协同决策。

### 6.4 实验验证

后续工作将在标准 LLM 基准上进行系统性实验，对比 BTCU 与传统 Agent 在幻觉率、决策准确率、安全指标和成本效率上的差异。

BTCU Harness 是一个以平衡三进制认知单元为内核，以 19683 离散状态空间为载体，以记忆生态与涌现式语义为特色的智能体认知驾驭架构。它为大模型与 Agent 提供了结构、灵魂、创造力和长期成长能力。

BTCU Harness 不替代大模型，而是让大模型驱动的 Agent 第一次拥有真正可内化、可演化、可解释、可自主的认知基础。

## 附录 A：19683 状态空间的形式化定义

**定义 1**（认知状态）：认知状态 $s$ 是一个九维三元向量：

$$s = (d_0, d_1, \dots, d_8), \quad d_i \in \{-1, 0, +1\}$$

**定义 2**（状态空间）：认知状态空间 $S$ 是所有认知状态的集合：

$$S = \{-1, 0, +1\}^9, \quad |S| = 3^9 = 19683$$

**定义 3**（状态编码）：状态 $s$ 的编码 $\text{idx}(s)$ 定义为：

$$\text{idx}(s) = \sum_{i=0}^{8} (d_i + 1) \cdot 3^i \in [0, 19682]$$

**定义 4**（认知距离）：状态 $s_a$ 和 $s_b$ 的认知距离：

$$\text{dist}(s_a, s_b) = \sum_{i=0}^{8} |d_i^a - d_i^b| \in [0, 18]$$

**定义 5**（取反态）：状态 $s$ 的取反态 $\bar{s}$：

$$\bar{s} = (-d_0, -d_1, \dots, -d_8), \quad \text{idx}(\bar{s}) = 19682 - \text{idx}(s)$$

**定理 1**（空态居中）：全空态 $s_0 = (0, 0, \dots, 0)$ 的编码为 9841，恰为状态空间的中点。

**定理 2**（取反对合）：$\bar{\bar{s}} = s$，即双重取反恢复原态。

**定理 3**（空态不变性）：$\bar{s_0} = s_0$，即空态在取反操作下不变。

## 附录 B：第三选择的形式化

**定义 6**（冲突分析）：给定两个状态 $s_a$ 和 $s_b$：
- 一致维度集 $A = \{i : d_i^a = d_i^b\}$
- 冲突维度集 $D = \{i : d_i^a \neq d_i^b\}$
- 对立维度集 $O = \{i : d_i^a + d_i^b = 0\} \subseteq D$

**定义 7**（第三选择）：第三选择 $s_c$ 定义为：

$$d_i^c = \begin{cases} d_i^a & \text{if } i \in A \\ 0 & \text{if } i \in D \end{cases}$$

**性质**：第三选择不是 $s_a$ 和 $s_b$ 的算术平均，而是在一致维度保持、在冲突维度置空的选择性合成。
