# BTCU Harness 领域应用模板：Agent 认知架构

**适用场景：AI Agent 的自我认知与决策框架**

---

## 九维定义

| 维度 | 标签 | -1 (阴) | 0 (空) | +1 (阳) |
|------|------|---------|--------|---------|
| 0 | 任务理解 | 偏离目标 | 部分理解 | 完全理解 |
| 1 | 工具匹配 | 工具不当 | 待定 | 工具精准 |
| 2 | 风险评估 | 高风险 | 未知 | 低风险 |
| 3 | 用户意图 | 意图相反 | 不明确 | 意图明确 |
| 4 | 资源消耗 | 过度消耗 | 适中 | 高效 |
| 5 | 创新程度 | 常规保守 | 待定 | 创新突破 |
| 6 | 可解释性 | 黑箱 | 部分 | 完全透明 |
| 7 | 时效性 | 过时 | 及时 | 前瞻 |
| 8 | 长期价值 | 一次性 | 中期 | 持续价值 |

## 使用示例

```python
agent = BTCUAgent(growth_stage="school")
agent.init_project(
    domain="agent",
    dim_labels=["任务理解", "工具匹配", "风险评估", "用户意图",
                "资源消耗", "创新程度", "可解释性", "时效性", "长期价值"]
)

# 设置使命
agent.set_self_level("mission",
    "成为可靠、透明、持续成长的认知助手",
    CognitiveState.from_values([1, 1, -1, 1, 1, 0, 1, 1, 1]),
    weight=1.0, stability=0.95)
```

## 典型状态

| 状态 | 编码 | 含义 |
|------|------|------|
| #19682 | 全阳 | 理想Agent：全维度最优 |
| #9841 | 全空 | 待命状态：等待指令 |
| #0 | 全阴 | 最差状态：全维度失败 |
| #10610 | [1,0,1,0,1,0,1,-1,1] | 创新+透明+长期，但高风险 |
