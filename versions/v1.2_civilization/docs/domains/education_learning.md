# BTCU Harness 领域应用模板：教育学习

**适用场景：学习状态评估与教学策略优化**

---

## 九维定义

| 维度 | 标签 | -1 (阴) | 0 (空) | +1 (阳) |
|------|------|---------|--------|---------|
| 0 | 知识掌握 | 完全未掌握 | 部分理解 | 完全掌握 |
| 1 | 学习动力 | 厌学抗拒 | 一般 | 高度投入 |
| 2 | 认知负荷 | 过载 | 适中 | 轻松 |
| 3 | 实践能力 | 无法应用 | 部分应用 | 熟练应用 |
| 4 | 创新思维 | 刻板模仿 | 常规思路 | 举一反三 |
| 5 | 协作能力 | 独立封闭 | 被动参与 | 主动协作 |
| 6 | 反思能力 | 不反思 | 偶尔反思 | 深度反思 |
| 7 | 学习策略 | 策略不当 | 模糊 | 策略精准 |
| 8 | 成长心态 | 固定心态 | 混合 | 成长心态 |

## 使用示例

```python
agent.init_project(
    domain="education",
    dim_labels=["知识掌握", "学习动力", "认知负荷", "实践能力",
                "创新思维", "协作能力", "反思能力", "学习策略", "成长心态"]
)

# 学习者状态评估
struggling = CognitiveState.from_values([-1, -1, -1, -1, -1, 0, -1, -1, -1])
# 索引 #8：知识未掌握+动力低+负荷过载+...

excelling = CognitiveState.from_values([1, 1, 1, 1, 1, 1, 1, 1, 1])
# 索引 #19682：全维度优秀

# 学习路径：从困难到优秀
path = agent.pathfinder.find_path(struggling, excelling)
# 距离 = 16 -> 穿越空态
# 先归空：放下"我不会"的执念
# 再逐步向阳：从成长心态(-1->0->1)开始

# 教学冲突：深度理解 vs 快速应试
deep_learning = CognitiveState.from_values([1, 1, -1, 1, 1, 0, 1, 1, 1])
# 深度理解：知识掌握+动力高+负荷重(深度思考)+创新+反思+成长
exam_prep = CognitiveState.from_values([0, 0, 1, 0, -1, 0, 0, 1, 0])
# 应试：负荷轻+策略精准但无创新

candidates = agent.third_choice_gen.generate_all(deep_learning, exam_prep)
# void策略：保留学习策略(都为阳)，在知识和创新上置空
# -> "先确保策略精准，在知识深度上保持开放"
```

## Bloom 认知层级映射

| Bloom 层级 | 对应维度 | BTCU 表现 |
|------------|----------|-----------|
| 记忆 | 维度0(知识掌握) | 阳=记住，阴=遗忘 |
| 理解 | 维度0+维度7 | 知识+策略都为阳 |
| 应用 | 维度3(实践能力) | 阳=能应用 |
| 分析 | 维度6(反思能力) | 阳=能分析 |
| 评价 | 维度6+维度4 | 反思+创新都为阳 |
| 创造 | 维度4(创新思维) | 阳=举一反三 |

## 学习阶段与状态空间

| 学习阶段 | 典型状态特征 | 教学策略 |
|----------|-------------|----------|
| 入门期 | 知识阴+负荷阴+策略阴 | 降低负荷，建立基础 |
| 理解期 | 知识空+负荷空+策略阳 | 引导发现，匹配策略 |
| 实践期 | 知识阳+实践阴+反思空 | 增加练习，鼓励反思 |
| 精通期 | 全阳或近全阳 | 挑战创新，教导他人 |
| 瓶颈期 | 部分阳+部分阴（冲突） | 第三选择：跳出当前维度 |
