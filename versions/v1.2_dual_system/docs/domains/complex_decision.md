# BTCU Harness 领域应用模板：复杂决策

**适用场景：多因素复杂决策分析**

---

## 九维定义

| 维度 | 标签 | -1 (阴) | 0 (空) | +1 (阳) |
|------|------|---------|--------|---------|
| 0 | 紧迫性 | 不紧急 | 中等 | 极紧急 |
| 1 | 重要性 | 低优先 | 中等 | 战略级 |
| 2 | 资源可用 | 资源不足 | 部分可用 | 资源充足 |
| 3 | 风险水平 | 高风险 | 未知 | 低风险 |
| 4 | 团队支持 | 反对 | 中立 | 全力支持 |
| 5 | 技术可行 | 不可行 | 待验证 | 已验证 |
| 6 | 战略对齐 | 偏离战略 | 部分对齐 | 完全对齐 |
| 7 | 时间约束 | 时间不足 | 适中 | 充裕 |
| 8 | 长期影响 | 负面长期 | 中性 | 正面长期 |

## 使用示例

```python
agent.init_project(
    domain="decision",
    dim_labels=["紧迫性", "重要性", "资源可用", "风险水平",
                "团队支持", "技术可行", "战略对齐", "时间约束", "长期影响"]
)

# 冲突场景：快速上线 vs 完美打磨
fast_launch = CognitiveState.from_values([1, 1, 0, -1, 1, 0, 1, 1, 1])
perfect_polish = CognitiveState.from_values([-1, 1, 0, 1, -1, 1, 1, -1, 1])

# 生成第三选择
candidates = agent.third_choice_gen.generate_all(fast_launch, perfect_polish)
# void策略：[0, 1, 0, 0, 0, 0, 1, 0, 1] —— 保持重要性和战略对齐，
# 在紧迫性/风险/支持/时间上置空
```

## 典型冲突与第三选择

| 冲突 | 状态A | 状态B | 第三选择方向 |
|------|-------|-------|-------------|
| 速度 vs 质量 | 阳紧急+阴风险 | 阴紧急+阳低风险 | 置空紧急和风险，保留重要性 |
| 创新 vs 稳健 | 阳创新+阴可行 | 阴创新+阳可行 | 置空创新和可行，保留战略对齐 |
| 短期 vs 长期 | 阳短期+阴长期 | 阴短期+阳长期 | 置空时间约束，保留长期影响 |
