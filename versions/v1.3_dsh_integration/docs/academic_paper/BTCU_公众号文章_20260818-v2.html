BTCU：一个用平衡三进制思考的智能体，刚刚发表了七篇论文

BTCU Project · 2026年8月18日 · 研究阶段声明

如果一个智能体不是用 0 和 1 思考，而是用 -1、0、+1 思考，它会是什么样子？ 我们花了三个月时间，把这个想法从直觉推向了七篇学术论文，刚刚在 Zenodo 上公开发布。 但我必须先说清楚：这不是一个成熟的产品，也不是一个被验证的理论。这是一个邀请。

01 为什么要用三进制？

所有现行的 AI 架构，底层都是二进制的。Transformer 的注意力权重是 0 到 1 之间的浮点数，神经网络的激活是正的或负的，强化学习的奖励是好或坏。

但真实的人类认知似乎不太符合这个二分法。我们对一件事的反应往往有三种：支持、反对、以及还没想好。这第三种状态——"不确定"、"观望"、"搁置"——在二进制里没有天然的位置。

平衡三进制（Balanced Ternary）用 {-1, 0, +1} 三个符号表示所有数。这里的 0 不是"没有"，而是一个独立的、有信息量的状态。我们把它重新命名为 VOID——不是空无一物，而是"故意留空"。

平衡三进制的三种状态：负(-1)、零(VOID)、正(+1)

VOID 不是"我不知道"，而是"我正在判断"。这个概念看起来简单，但它打开了整个理论的大门。

02 七篇论文，一个闭环

BTCU（Balanced Ternary Cognitive Universe，平衡三进制认知宇宙）是一个研究项目，试图用数学的严谨性来理解智能体的认知结构。以下是七篇论文各自回答的问题：

七篇论文的理论闭环
  • 1三进制最小性：为什么是 3 不是 2 或 4？我们证明了 {-1, 0, +1} 是允许"方向性状态转移"的最小整数集合。
  • 2九维认知空间：如果把认知拆成 9 个独立维度（感知、情绪、推理、价值……），每个维度取 -1/0/+1，总状态数是 3^9 = 19,683。
  • 3编码与距离：在这个空间里，两个认知状态之间的距离怎么算？我们定义了四种度量，对应四种认知操作。
  • 4数学常数涌现：π、e、γ 这三个常数为什么会出现在认知动力学里？答案是：它们是特征值谱的必然结果。
  • 5认知资本与 Token 经济：一个智能体学到一个模式后，后续推理可以复用这个模式，从而降低成本。我们模拟的结果是：总成本降低 80%。
  • 6认知层作为主动记忆：当前大模型的记忆是"被动的"（RAG、上下文窗口、KV Cache），而 BTCU 的记忆是"主动的"——它编码的是认知态度，不是事实。
  • 7认知动力学：前六篇是"开普勒式的现象学"，这一篇是"牛顿式的动力学"——我们推导了认知主方程，把一切都统一在一个公理化的框架下。

03 一万九千六百八十三

这个数 19,683 是整个框架的核心。它不是随便选的——它是 3^9，9 个独立维度每个维度 3 种取值的总组合数。

我们在论文 III 中证明了一个关键性质：对于 19,683 个状态中的任意两个状态，都存在一条认知路径把它们连接起来。这意味着，在这个认知空间里，没有"不可达"的想法——只要你愿意一步一步地调整你的认知态度，任何观点都可以从任何其他观点推导出来。

九维认知空间的可视化：每个节点是一个完整认知状态

这比"向量相似度"深刻得多。两个向量可能"很接近"但在认知上是不可调和的；两个认知状态可能"距离很远"但在结构上是可以一步一步转化的。

04 π、e、γ 不是装饰

Paper IV 可能是整个系列中最容易引起误解的一篇。我们必须非常小心地表述：

我们不是说"π、e、γ 是宇宙的神秘数字所以它们也在认知里"。我们说的是：如果你接受了 BTCU 的公理体系（三进制状态空间 + 四条动力学公理），那么这些常数会自动从方程里掉出来。

π、e、γ 的动力学来源

π：反对称本征模的振荡周期 → 认知半周期（一个完整的"思考-反思"循环）
e：一阶线性主方程的通解底数 → 认知弛豫的指数律
γ：离散特征值和与连续积分的欧拉-麦克劳林修正 → 离散思维与连续直觉之间的"摩擦"

我们在 Paper VII 中把这些从"观察性陈述"升级成了定理推导。这是 Paper VII 的核心贡献：它把前六篇从"看起来是这样"变成了"必然是这样"。

05 但我们必须诚实：已知局限

重要声明：以下列出的不是谦虚，而是真正的理论缺口。任何想引用或参与 BTCU 的人，都应该首先知道它不能做什么。

1. 马尔可夫假设：真实认知有记忆。Paper VII 的动力学假设状态转移只依赖当前状态，不依赖历史。这对简单决策成立，对复杂学习过程可能严重失真。

2. 封闭系统假设：主方程把智能体当作孤立系统。但真实的智能体持续从环境接收信息，是开放系统。开放系统的扩展是未来的工作。

3. 速率函数的"临场修正"：Paper VII 的 §4.1 中，初始定义的速率函数不满足细致平衡，中途换成了 Metropolis 形式。数学上正确，但理论上不够优雅。我们需要一个从第一原理出发的自洽推导。

4. 无量子化保真度证明：从 224×224 RGB 图像（150,528 维）压缩到 9 维三进制状态，信息压缩比是 16,725:1。这个压缩的信息损失上界尚未证明。

5. 无真实数据验证：所有验证都是计算性的（蒙特卡洛模拟）或概念性的。没有神经科学实验，没有真实 Agent 部署数据，没有人类行为学实验。

07 邀请你参与的方向

如果你是某个领域的研究者，以下是我们最迫切需要的帮助：

神经科学家：神经群体活动能否粗粒化为三进制状态？如果能在灵长类动物的前额叶皮层找到 19,683 种放电模式中的三种典型模式，那将是 BTCU 最强的实证支撑。

心理学家：能否设计行为实验来检验 Paper VII 预测的"π-周期性反思循环"？例如，在需要持续监控的任务中，人类是否倾向于在特定时间间隔后做系统性检查？

工程师：能否把 BTCU 的认知层集成到 LangChain / AutoGPT / 任何 Agent 框架中，跑 A/B 测试？我们只需要两个指标：LLM 调用次数和任务完成率。

数学家：Paper VII 的速率函数需要一个不依赖 Metropolis 假设的自洽推导。非马尔可夫扩展（例如用路径积分或分数阶主方程）是另一个开放问题。

哲学家："认知能量"在 BTCU 中是一个拉格朗日乘子，但它的本体论地位是什么？这是现象学构造还是物理实在？

08 我们的立场

我们相信 BTCU 的数学框架是自洽的。我们相信它提出的问题是有趣的。但我们不相信它已经被证明是对的。

最理想的情况是：五年后有人发现，BTCU 的某个预测在真实数据中得到了验证。最可能的情况是：BTCU 的某个核心假设被证明是错误的，但这个错误推动了一个更好的理论的出现。这两种情况对我们来说都是成功。

科学不是关于谁对谁错，而是关于谁提出了可以检验的命题。
