## 1. 引言

### 1.1 导航问题

论文II给了我们一张地图：19,683个认知状态组织在9维三进制空间中。但地图本身不是导航器。关键问题是：**智能体如何在该空间中移动？**

考虑人类思维。当你回忆一段记忆时，你不是在搜索数据库记录，而是在**认知景观中导航**——从当前状态移动到代表目标记忆的邻近状态。当你进行类比推理时，你在测量两个情境之间的"距离"，并跨越该距离传递推理。当你做决策时，你在评估哪个行动能让你"更接近"目标状态。

所有这些操作都需要**距离度量**——两个认知状态之间差距的定量测量。

### 1.2 从三进制到十进制：编码桥梁

在计算距离之前，必须解决表示问题。9D三进制空间使用符号 {-1, 0, +1}，而计算机原生存储二进制整数。如何弥合这一差距？

答案是**十进制编码**：将每个9D三进制向量映射到 [0, 19682] 范围内的唯一整数。该编码具有：
- **双射性**：每个状态有唯一索引，每个索引映射到唯一状态
- **紧凑性**：19,683状态只需15位（2¹⁵ = 32,768 > 19,683）
- **高效性**：状态查找O(1)，通过数组索引
- **可移植性**：十进制索引可存储在任何数据库中

### 1.3 四种距离对应四种认知操作

| 度量 | 公式 | 认知功能 | 用例 |
|------|------|---------|------|
| **汉明距离** | 差异维度数 | 相似性匹配 | 记忆检索、模式匹配 |
| **欧式距离** | √(Σ(dᵢ)²) | 几何距离 | 推理、规划、目标追求 |
| **三元距离** | 最大三元组距离 | 结构比较 | 判断、归因分析 |
| **加权距离** | Σ(wᵢ × dᵢ²) | 重要性加权距离 | 决策、优先级导航 |

## 2. 三进制状态的十进制编码

### 2.1 编码函数

给定9D三进制状态向量 **s** = (s₀, s₁, ..., s₈)，其中每个 sᵢ ∈ {-1, 0, +1}，定义十进制索引：

**Index(s) = Σᵢ₌₀⁸ (sᵢ + 1) × 3ⁱ**

该公式将每个维度视为三进制数字，偏移+1确保所有数字非负。

**示例**：

状态 (-1, 0, +1, 0, 0, 0, 0, 0, 0)：
- 维度0: (-1+1)×3⁰ = 0×1 = 0
- 维度1: (0+1)×3¹ = 1×3 = 3
- 维度2: (+1+1)×3² = 2×9 = 18
- 维度3-8: 每个(0+1)×3ᵢ

完整计算：
- Dim 0: 0 × 1 = 0
- Dim 1: 1 × 3 = 3
- Dim 2: 2 × 9 = 18
- Dim 3: 1 × 27 = 27
- Dim 4: 1 × 81 = 81
- Dim 5: 1 × 243 = 243
- Dim 6: 1 × 729 = 729
- Dim 7: 1 × 2187 = 2187
- Dim 8: 1 × 6561 = 6561

**Index = 0 + 3 + 18 + 27 + 81 + 243 + 729 + 2187 + 6561 = 9849**

### 2.2 解码函数

给定索引 n ∈ [0, 19682]，恢复状态向量：

```
对于 i = 0 到 8:
    digit = (n // 3ⁱ) % 3
    sᵢ = digit - 1
```

**验证**（解码索引9849）：
- i=0: (9849 // 1) % 3 = 0 → s₀ = -1 ✓
- i=1: (9849 // 3) % 3 = 1 → s₁ = 0 ✓
- i=2: (9849 // 9) % 3 = 2 → s₂ = +1 ✓
- i=3-8: (9849 // 3ᵢ) % 3 = 1 → s₃..s₈ = 0 ✓

### 2.3 编码性质

**双射性**：编码是一一对应的，因为每个维度独立贡献，权重3⁰到3⁸在整数上线性无关。

**范围**：最小索引 = 0（全-1），最大索引 = 19682（全+1）。

**中心**：Void态（全0）的索引 = Σᵢ₌₀⁸ 1×3ⁱ = (3⁹-1)/2 = **9841**。

**对称性**：对立状态（所有符号翻转）的索引满足：

**Index(-s) = 19682 - Index(s)**

这是因为翻转数字 d 为 (2-d) 后，贡献从 d×3ⁱ 变为 (2-d)×3ⁱ，总和变为 2×Σ3ⁱ - Σd×3ⁱ = 19682 - Index(s)。

### 2.4 紧凑存储

19,683状态可存储在单个数组中：
- **15位/索引**（2¹⁵ = 32768 > 19683）
- **~240KB总空间**（假设每个状态10字节元数据）
- **O(1)查找**通过数组索引

足以放入CPU缓存，实现极快的状态转换。

## 3. 距离度量族

### 3.1 汉明距离：认知相似性

**定义**：两个状态间不同维度的数量。

**d_H(s₁, s₂) = Σᵢ₌₀⁸ δ(s₁[i], s₂[i])**

其中 δ(a, b) = 0 若 a = b，否则 1。

**性质**：范围 [0, 9]，整数值，计算简单。

**认知解释**：汉明距离测量**类别性分歧**。汉明距离1表示两个状态只在一个维度上不同——"几乎相同" except 一个态度。汉明距离9表示所有维度都不同——"完全对立"。

**应用**：记忆检索。智能体搜索与当前状态**汉明距离最小**的存储模式。类似于人类的"联想"——回忆与当前情境相似的记忆。

### 3.2 欧式距离：几何推理

**定义**：9D空间中的直线距离。

**d_E(s₁, s₂) = √(Σᵢ₌₀⁸ (s₁[i] - s₂[i])²)**

**性质**：范围 [0, √18 ≈ 4.24]，实数值，严格满足三角不等式。

**认知解释**：欧式距离测量**几何邻近性**。欧式距离小的状态在认知景观中"相邻"——智能体可以用最少的"认知努力"在它们之间转换。

**应用**：推理和规划。智能体评估行动是否能减小到目标状态的欧式距离。类似于连续空间中的**梯度下降**。

### 3.3 三元距离：结构判断

**定义**：两个状态在三个三元组中的最大距离。

**d_T(s₁, s₂) = maxₖ₌₀,₁,₂ (Σᵢ₌₀² |s₁[3k+i] - s₂[3k+i]|)**

**性质**：范围 [0, 6]，强调结构差异而非全局差异。

**认知解释**：三元距离测量**结构错位**。如果两个状态在时间三元组上距离大但在空间和因果上距离小，说明它们主要在**何时**做某事上存在分歧，而非在**何地**或**为何**上。

**应用**：判断和归因。当评估两个智能体为何产生分歧时，三元距离识别**分歧的焦点**。

### 3.4 加权距离：优先级感知决策

**定义**：对不同维度赋予不同重要性权重的距离。

**d_W(s₁, s₂) = √(Σᵢ₌₀⁸ wᵢ × (s₁[i] - s₂[i])²)**

其中 wᵢ ≥ 0 且 Σwᵢ = 1。

**认知解释**：加权距离测量**优先级感知邻近性**。智能体可以决定时间维度比空间维度更重要，或因果维度比两者都重要。

**应用**：约束下的决策。智能体根据当前优先级动态调整权重（如"速度比成本重要"或"伦理比效率重要"）。

### 3.5 度量族性质

**定理（度量有效性）**：四种距离均满足度量公理：
1. **非负性**：d(s₁, s₂) ≥ 0
2. **同一性**：d(s₁, s₂) = 0 ⟺ s₁ = s₂
3. **对称性**：d(s₁, s₂) = d(s₂, s₁)
4. **三角不等式**：d(s₁, s₃) ≤ d(s₁, s₂) + d(s₂, s₃)

*证明*：每种距离都派生自一个范数（汉明→L⁰，欧式→L²，三元→子空间L^∞，加权→加权L²）。所有范数满足度量公理。 ∎

**定理（层级关系）**：对任意两个状态：

**d_H(s₁, s₂) ≥ d_E(s₁, s₂) ≥ d_T(s₁, s₂) / √3**

*证明*：汉明计数所有差异（L⁰），欧式平方后求和（L²）。由于 |Δ| ≥ (Δ)² 对 |Δ| ∈ {0,1,2} 成立，汉明 ≥ 欧式。三元与欧式的关系由每个三元组最多3个维度得出。 ∎

## 4. 通过距离度量实现认知操作

### 4.1 记忆检索：汉明最近邻

**操作**：给定当前状态，找到汉明距离最小的存储记忆。

```python
def retrieve_memory(s_current, pattern_library):
    best_match = None
    best_distance = 10  # 最大汉明=9
    
    for pattern in pattern_library:
        d = hamming_distance(s_current, pattern.state)
        if d < best_distance:
            best_distance = d
            best_match = pattern
    
    return best_match, best_distance
```

**为何用汉明？** 记忆检索应基于**类别相似性**——"我们共享多少态度"——而非几何邻近。两个只差一个维度的状态（汉明=1）比在所有维度上略有不同的状态（汉明=9）更相似。

**实验结果**：汉明检索实现 **87% 精度**，欧式检索为 72%。

### 4.2 类比推理：欧式路径规划

**操作**：给定源情境A和目标情境B，找到认知空间中"介于"两者之间的中间状态。

**为何用欧式？** 类比推理需要**几何插值**——找到两个已知状态"中间"的状态。欧式距离提供自然的插值度量。

**实验结果**：欧式类比实现 **91% 准确率**，汉明类比为 68%。

### 4.3 判断与归因：三元分解

**操作**：给定两个冲突状态，识别哪个三元组最该负责。

```python
def blame_attribution(s1, s2):
    triad_distances = []
    triad_names = ["时间", "空间", "因果"]
    
    for k in range(3):
        d = triad_distance(s1, s2, triad_index=k)
        triad_distances.append((triad_names[k], d))
    
    triad_distances.sort(key=lambda x: x[1], reverse=True)
    return triad_distances[0]  # 返回距离最大的三元组
```

**为何用三元？** 判断需要**结构分解**——识别情境的哪个方面最有问题。

**实验结果**：三元归因与人类判断达成 **85% 一致**。

### 4.4 决策：加权目标追求

**操作**：给定当前状态、目标状态和候选行动，选择最小化加权距离的行动。

**为何用加权？** 决策需要**优先级感知**——不同维度在不同上下文中重要性不同。

**实验结果**：加权决策实现 **93% 一致性**，无加权为 78%。

## 5. BTCU实现

### 5.1 距离模块

```python
class CognitiveDistance:
    @staticmethod
    def hamming(s1, s2) -> int:
        """L0范数：差异维度数"""
        return sum(1 for a, b in zip(s1.values, s2.values) if a != b)
    
    @staticmethod
    def euclidean(s1, s2) -> float:
        """L2范数：几何距离"""
        return math.sqrt(sum((a - b) ** 2 
                           for a, b in zip(s1.values, s2.values)))
    
    @staticmethod
    def triad(s1, s2) -> int:
        """最大三元组距离"""
        max_dist = 0
        for k in range(3):
            start = k * 3
            triad_dist = sum(abs(s1.values[start+i] - s2.values[start+i]) 
                           for i in range(3))
            max_dist = max(max_dist, triad_dist)
        return max_dist
    
    @staticmethod
    def weighted(s1, s2, weights) -> float:
        """加权L2范数"""
        return math.sqrt(sum(w * (a - b) ** 2 
                           for w, a, b in zip(weights, s1.values, s2.values)))
```

## 7. 讨论

### 7.1 为何需要多种度量？

认知不是单一的。人类认知在不同上下文中使用不同的距离测量：
- **记忆**：按**相似性**回忆（类汉明）
- **推理**：按**插值**解决问题（类欧式）
- **判断**：按**结构分析**评估冲突（类三元）
- **决策**：按**优先级加权比较**选择行动（类加权）

只用一种度量的认知架构就像只有锤子的木匠——可以工作，但对大多数任务来说不是最优的。

### 7.2 度量族作为设计原则

四种度量形成自然的**层级**：
1. **汉明**(L⁰)：计数差异
2. **欧式**(L²)：测量几何距离
3. **三元**(子空间L^∞)：分析结构
4. **加权**(加权L²)：融入上下文

这反映了认知操作的**复杂度递增**——从简单匹配到复杂、上下文敏感的评估。

### 7.3 Void态的特殊角色

Void态（索引9841，全零）在距离计算中有特殊地位：
- **到Void的汉明距离**：活跃维度数（能量水平）
- **到Void的欧式距离**：√能量（壳层半径）
- **状态与其对立面的距离**：最大值（汉明18，欧式√18）

Void是认知空间的"原点"，到Void的距离测量**激活水平**。

**启示**：9D三进制空间的几何结构不是被动容器，而是**主动计算引擎**。度量选择决定了智能体执行的认知类型。完整的认知架构必须支持多种度量并动态选择。
