# BTCU Harness 领域应用模板：心理认知

**适用场景：心理咨询与认知状态评估**

---

## 九维定义

| 维度 | 标签 | -1 (阴) | 0 (空) | +1 (阳) |
|------|------|---------|--------|---------|
| 0 | 情绪基调 | 抑郁低落 | 平和 | 积极愉悦 |
| 1 | 认知清晰 | 思维混乱 | 一般 | 思维清晰 |
| 2 | 自我评价 | 自我否定 | 中性 | 自我接纳 |
| 3 | 人际关系 | 孤立回避 | 一般 | 主动连接 |
| 4 | 行为动力 | 退缩无力 | 正常 | 积极行动 |
| 5 | 压力水平 | 过载崩溃 | 适中 | 轻松应对 |
| 6 | 睡眠质量 | 严重障碍 | 一般 | 良好 |
| 7 | 现实感 | 脱离现实 | 一般 | 现实感强 |
| 8 | 成长意愿 | 抗拒改变 | 中性 | 渴望成长 |

## 使用示例

```python
agent.init_project(
    domain="psychology",
    dim_labels=["情绪基调", "认知清晰", "自我评价", "人际关系",
                "行为动力", "压力水平", "睡眠质量", "现实感", "成长意愿"]
)

# 来访者状态：抑郁倾向
depressed = CognitiveState.from_values([-1, -1, -1, -1, -1, -1, -1, 0, -1])
# 索引 #2：全阴除现实感为空

# 健康状态
healthy = CognitiveState.from_values([1, 1, 1, 1, 1, 1, 1, 1, 1])
# 索引 #19682：全阳

# 治疗路径：从抑郁到健康
path = agent.pathfinder.find_path(depressed, healthy)
# 距离 = 16，会自动选择穿越空态路径
# 先归空（释放当前状态），再逐步向阳

# 第三选择：来访者想"努力变好"但又"害怕改变"
effort = CognitiveState.from_values([0, 0, 0, 0, 1, -1, 0, 0, 1])  # 想努力
fear = CognitiveState.from_values([-1, 0, -1, -1, -1, -1, -1, 0, -1])  # 怕改变
candidates = agent.third_choice_gen.generate_all(effort, fear)
# void策略：保留空维，在行为动力上冲突置空
# -> "不急于改变行为，先在认知层面接纳恐惧"
```

## 心理状态与认知空间

| 心理状态 | 对应状态特征 | 典型索引范围 |
|----------|-------------|-------------|
| 抑郁发作 | 全阴或近全阴 | 0-100 |
| 焦虑状态 | 高阴+部分阳（矛盾） | 混合极性 |
| 正念状态 | 高空度（不执著） | 接近 9841 |
| 心流状态 | 全阳或近全阳 | 19000-19682 |
| 矛盾状态 | 阴阳对半（冲突） | 中间区域 |

## 治疗路径设计

```
抑郁状态(全阴)
    |
    v [穿越空态] —— 接纳当前状态，不急于改变
    |
全空态(#9841) —— 正念：不评判地觉察
    |
    v [逐步向阳] —— 从最易改变的维度开始
    |
    +-- 维度8(成长意愿): -1 -> 0 "开始有改变的想法"
    +-- 维度6(睡眠): -1 -> 0 "睡眠开始改善"
    +-- 维度2(自我评价): 0 -> 1 "开始自我接纳"
    v
健康状态(全阳)
```
