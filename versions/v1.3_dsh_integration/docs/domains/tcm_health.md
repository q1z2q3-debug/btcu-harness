## 九维定义

| 维度 | 标签 | -1 (阴) | 0 (空) | +1 (阳) |
|------|------|---------|--------|---------|
| 0 | 寒热 | 寒证 | 正常 | 热证 |
| 1 | 虚实 | 虚证 | 平 | 实证 |
| 2 | 表里 | 里证 | 半表半里 | 表证 |
| 3 | 气血 | 气虚/血虚 | 平衡 | 气盛/血盛 |
| 4 | 湿燥 | 湿重 | 适中 | 燥盛 |
| 5 | 阴阳 | 阴盛 | 平衡 | 阳亢 |
| 6 | 脏腑 | 脏病 | 经络 | 腑病 |
| 7 | 情志 | 情志抑郁 | 平和 | 情志亢奋 |
| 8 | 体质 | 偏寒体质 | 平和体质 | 偏热体质 |

## 使用示例

```python
agent.init_project(
    domain="diagnosis",
    dim_labels=["寒热", "虚实", "表里", "气血",
                "湿燥", "阴阳", "脏腑", "情志", "体质"]
)

# 辨证：患者表现为发热、口渴、脉数
# 热证(+) + 实证(+) + 里证(-) + 气血盛(+) + 燥(+) + 阳亢(+) + 腑病(+) + 亢奋(+) + 热体质(+)
heat_syndrome = CognitiveState.from_values([1, 1, -1, 1, 1, 1, 1, 1, 1])
# 索引 #19358

# 对比：寒证患者
cold_syndrome = CognitiveState.from_values([-1, -1, -1, -1, -1, -1, -1, -1, -1])
# 索引 #0 = 全阴

# 第三选择：寒热错杂
mixed = agent.third_choice_gen.generate_all(heat_syndrome, cold_syndrome)
# void策略 -> 全空态 #9841：症状信息不足，需要更多诊断
```
