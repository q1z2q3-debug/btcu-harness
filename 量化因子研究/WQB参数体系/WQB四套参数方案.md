# WorldQuant BRAIN 全套参数调优方案（USA/D1/TOP2000 合规版）

## 一、全部参数释义（默认基准配置）

| 参数 | 默认值 | 核心功能说明 |
|------|--------|-------------|
| LANGUAGE | Fast Expression | 模型默认编译语法，固定配置，无需改动 |
| INSTRUMENT TYPE | Equity | 标的类型为权益资产，固定配置 |
| REGION | USA | 限定北美市场样本池，固定配置 |
| UNIVERSE | TOP2000 | 选取市场流动性靠前 2000 只标的，可按需切换 TOP1000 / TOP3000 |
| DELAY | 1 | 信号延迟机制，1 代表当日生成信号、次周期执行，保证逻辑无前瞻偏差 |
| NEUTRALIZATION | Sector | 粗维度板块中性化，剥离板块整体波动影响，可切换市场/细分行业/无中性模式 |
| DECAY | 4 | 信号平滑衰减系数，数值越大信号越平稳、调仓频次越低；数值越小信号越灵敏 |
| TRUNCATION | 0.08 | 尾部极值压缩比例，上下各过滤 8% 异常样本，降低极端行情对模型的干扰 |
| PASTEURIZATION | On | 样本纯净度过滤，剔除不在选定样本池内的标的，规避低流动性样本干扰 |
| UNIT HANDLING | Verify | 截面标准化处理，默认标准化校验；支持排名标准化、无标准化两种模式 |
| NAN HANDLING | On | 缺失值补全机制，保障样本数量充足，避免数据断层 |
| TEST PERIOD | 0Y0M | 全周期回溯测试，可自定义 5 年 / 10 年短周期，适配不同市场结构测试 |

## 二、四套可直接套用的参数优化方案

### 方案 1：标准稳健通用版（适配迭代、通过率高）

**优化目标**：信号稳定、IC 质量均匀、波动可控、换手适中，适配绝大多数基础模型迭代

| 参数 | 优化后数值 | 调优逻辑 |
|------|-----------|---------|
| UNIVERSE | TOP2000（保留） | 流动性与样本容量均衡，适配多数中低频模型 |
| DELAY | 1（保留） | 遵循标准延迟规则，保证逻辑严谨无偏差 |
| NEUTRALIZATION | Industry | 细分行业中性化，相比板块中性，可更彻底剥离行业结构性噪音 |
| DECAY | 6 | 适度放大平滑系数，降低换手、提升信号稳定性与盈亏比 |
| TRUNCATION | 0.10 | 适度扩大极值过滤范围，压制个股异常波动带来的信号失真 |
| PASTEURIZATION | On（保留） | 保证样本纯净度，规避劣质样本干扰 |
| UNIT HANDLING | Rank | 全域排名标准化，消除量纲、市值、波动差异，模型信号更纯粹 |
| NAN HANDLING | On（保留） | 维持完整样本量，保证回溯结果可信 |
| TEST PERIOD | 10Y 0M | 选取近十年市场周期，规避早期极端市场结构造成的过度拟合 |

**适用场景**：趋势、反转、估值类基础模型，主打稳定迭代、低过拟合、高通过率。

### 方案 2：高灵敏进攻版（短线高频信号专用）

**优化目标**：强化短期信号捕捉能力，提升短期预测效度，适配中短周期异动模型

| 参数 | 优化后数值 | 调优逻辑 |
|------|-----------|---------|
| UNIVERSE | TOP1000 | 选取头部高流动性标的，冲击成本更低，短线信号有效性更强 |
| DELAY | 1（保留） | 严格遵循实盘延迟逻辑，保证合规可用 |
| NEUTRALIZATION | Sector（保留） | 保留粗维度板块波动，吃准短期板块轮动收益 |
| DECAY | 2 | 缩小平滑系数，侧重近期价格、量能异动信号，提升灵敏度 |
| TRUNCATION | 0.05 | 减少极值过滤，保留尾部超额收益机会，适配短线波动套利 |
| PASTEURIZATION | On | 纯净样本过滤 |
| UNIT HANDLING | Verify | 保留原始信号幅度差异，精准捕捉强弱偏离度 |
| NAN HANDLING | On | 保障数据完整性 |
| TEST PERIOD | 5Y 0M | 选用近五年市场结构，贴合当下交易环境，放大短线信号优势 |

**适用场景**：短期异动、资金流向、量能突变、快速反转类短周期模型。

### 方案 3：低换手长线稳态版（基本面价值模型专用）

**优化目标**：极低调仓频次、高稳定性、超大容量，适配长期基本面逻辑

| 参数 | 优化后数值 | 调优逻辑 |
|------|-----------|---------|
| UNIVERSE | TOP3000 | 扩大样本覆盖，分散持仓风险，大幅提升模型容量 |
| DELAY | 1 | 标准延迟配置 |
| NEUTRALIZATION | Market | 全市场中性化，剥离大盘整体涨跌，只保留个股相对强弱收益 |
| DECAY | 12 | 大幅拉长平滑周期，信号长期稳态，最大程度降低换手 |
| TRUNCATION | 0.12 | 强极值过滤，杜绝周期股、极端行业样本主导模型逻辑 |
| PASTEURIZATION | On | 保持样本纯净 |
| UNIT HANDLING | Rank | 排名标准化，消除长期市值漂移、风格偏移问题 |
| NAN HANDLING | On | 保证全周期样本稳定 |
| TEST PERIOD | 0Y0M（全周期） | 跨越多轮牛熊周期，验证长期逻辑有效性 |

**适用场景**：盈利质量、估值、毛利率、资产效率等长线基本面模型。

### 方案 4：异常值修复稳回撤版（高波动模型专用）

**优化目标**：压制极端回撤、降低整体波动、修复尾部异常样本带来的绩效失真

| 参数 | 优化后数值 | 调优逻辑 |
|------|-----------|---------|
| UNIVERSE | TOP2000 | 均衡流动性样本池 |
| DELAY | 1 | 标准固定配置 |
| NEUTRALIZATION | Subindustry | 最细粒度子行业中性，最大限度剥离行业周期与结构性扰动 |
| DECAY | 8 | 中高平滑系数，缓冲单日极端涨跌带来的信号跳变 |
| TRUNCATION | 0.15 | 最大化极值过滤，彻底剔除黑天鹅式异常样本干扰 |
| PASTEURIZATION | On | 样本纯净过滤 |
| UNIT HANDLING | Rank | 排名标准化，提升模型抗波动能力 |
| NAN HANDLING | On | 保证样本连续完整 |
| TEST PERIOD | 0Y0M | 全周期校验稳定性 |

**适用场景**：波动率、价差、杠杆属性等高波动模型，适合回撤偏大的模型修复优化。

## 三、分层迭代调参思路（标准化网格优化流程）

可按以下由浅入深的顺序迭代调参，避免一次性全量修改，方便定位最优参数：

### 第一层：中性化模式迭代顺序

无中性 → 板块中性 → 行业中性 → 细分行业中性 → 市场中性

- 短线、趋势模型：优先板块中性 / 无中性
- 长线基本面模型：优先行业中性 / 市场中性

### 第二层：衰减系数 Decay 迭代区间

可选数值：2、4、6、8、10、12

- 短线量能异动：2–4
- 中线均衡模型：4–6
- 长线基本面模型：8–12

### 第三层：极值截断 Truncation 迭代区间

可选数值：0.05、0.08、0.10、0.12、0.15

- 波动大、回撤高：加大截断数值
- 短线抓尾部收益：缩小截断数值

### 第四层：样本池 Universe 迭代切换

TOP1000 → TOP2000 → TOP3000

- 短线高频、量能模型：TOP1000
- 长线低频、大容量模型：TOP3000

### 第五层：标准化模式二选一

- Rank 排名标准化：稳定性强、抗异常、适配绝大多数模型
- Verify 差值标准化：保留原始信号幅度，适配价差、波动类模型
