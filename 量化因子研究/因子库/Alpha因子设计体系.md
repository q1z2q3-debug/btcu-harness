# Alpha 因子设计体系

> 对标 WorldQuant BRAIN 平台因子研究范式
> 设计原则：逻辑可解释 + 统计可验证 + 低相关可组合

---

## 一、因子分类体系

### 1. 量价因子 (Price-Volume)
基于价格和成交量数据挖掘市场微观结构信息

| 编号 | 因子名称 | 核心逻辑 | 公式思路 |
|------|---------|---------|---------|
| PV01 | 量价背离 | 价涨量缩/价跌量增预示反转 | -1 * correlation(open, volume, 10) |
| PV02 | 振幅因子 | 日内波动大的股票后续表现 | (high - low) / close |
| PV03 | 成交量排名 | 量能异动与未来收益关系 | rank(volume) |
| PV04 | 量价趋势共振 | 短期量价同向度 | correlation(close, volume, 5) |
| PV05 | 跳空缺口 | 开盘跳空的收益预测 | (open - close_1) / close_1 |

### 2. 动量反转因子 (Momentum & Reversal)
捕捉趋势延续或反转效应

| 编号 | 因子名称 | 核心逻辑 | 公式思路 |
|------|---------|---------|---------|
| MR01 | 短期反转 | 短期超跌反弹/超涨回调 | -1 * ts_delta(close, 1) |
| MR02 | 中期动量 | 中期趋势延续 | ts_sum(close, 5) - ts_sum(close, 10) |
| MR03 | 长期反转 | 长期均值回归 | -1 * ts_returns(close, 20) |
| MR04 | 动量加速度 | 动量变化率预测反转 | ts_delta(ts_returns(close, 5), 3) |
| MR05 | 高低点动量 | 突破与回归信号 | close / ts_max(close, 20) |

### 3. 波动率因子 (Volatility)
风险与收益的非线性关系

| 编号 | 因子名称 | 核心逻辑 | 公式思路 |
|------|---------|---------|---------|
| VL01 | 历史波动率 | 低波异象（低波动股长期跑赢） | -1 * ts_stddev(close, 20) |
| VL02 | 波动率变化 | 波动率突变的预测力 | ts_delta(ts_stddev(close, 10), 5) |
| VL03 | 下行波动率 | 下行风险比上行更重要 | ts_stddev(low, 20) / ts_stddev(high, 20) |
| VL04 | 成交量波动 | 量能稳定性 | -1 * ts_stddev(volume, 20) |

### 4. 技术形态因子 (Technical Pattern)
基于技术指标的形态识别

| 编号 | 因子名称 | 核心逻辑 | 公式思路 |
|------|---------|---------|---------|
| TP01 | RSI 超买超卖 | 相对强弱指数反转 | RSI类似逻辑，过涨卖过跌买 |
| TP02 | MACD 背离 | 指数平滑异同移动平均 | ts_mean(close, 12) - ts_mean(close, 26) |
| TP03 | 布林带位置 | 价格在波动区间的位置 | (close - ts_mean(close, 20)) / ts_stddev(close, 20) |
| TP04 | 均线排列 | 多头/空头排列强度 | ts_mean(close, 5) - ts_mean(close, 20) |

### 5. 基本面/质量因子 (Fundamental & Quality)
公司基本面特征（若有数据）

| 编号 | 因子名称 | 核心逻辑 | 公式思路 |
|------|---------|---------|---------|
| FQ01 | 价值因子 | 低估值股票长期超额收益 | 类似PE/PB倒数，估值越低得分越高 |
| FQ02 | 盈利质量 | 高质量公司持续跑赢 | 类似ROE/ROA，盈利越高得分越高 |

### 6. 情绪/资金流因子 (Sentiment & Flow)
市场情绪与资金流向

| 编号 | 因子名称 | 核心逻辑 | 公式思路 |
|------|---------|---------|---------|
| SF01 | 量能乖离 | 成交量偏离常态的信号 | volume / ts_mean(volume, 20) |
| SF02 | 价格位置 | 接近区间高点/低点的情绪含义 | (close - ts_min(low, 20)) / (ts_max(high, 20) - ts_min(low, 20)) |

## 二、因子标准化处理流程

每个因子构建完成后，按以下流程标准化：

### Step 1: 去极值 (Truncation/Winsorize)
```
因子值 = ts_truncate(因子值, -3, 3)  # 3倍标准差截断
```

### Step 2: 中性化 (Neutralization)
```
因子值 = group_neutralize(因子值, sector)  # 行业中性
因子值 = neutralize(因子值, market_cap)    # 市值中性
```

### Step 3: 标准化 (Standardization)
```
因子值 = rank(因子值)  # 横截面排名
或
因子值 = zscore(因子值)  # Z-Score标准化
```

### Step 4: 衰减平滑 (Decay)
```
因子值 = decay_linear(因子值, 5)  # 线性衰减平滑，降低换手率
```

### Step 5: 延迟 (Delay)
```
因子值 = delay(因子值, 1)  # 延迟1天，模拟T+1可交易
```

## 三、回测评估指标

| 指标 | 含义 | 判断标准 |
|------|------|---------|
| Sharpe Ratio | 风险调整后收益 | >1可接受，>2优秀 |
| Fitness | 综合评分（平台核心） | 越高越好 |
| IC (信息系数) | 因子与下期收益的相关系数 | |IC|>0.03有预测力 |
| Rank IC | 排名相关系数 | >0.03有意义，>0.05较好 |
| IR (信息比率) | IC均值 / IC标准差 | >0.5可接受，>1优秀 |
| Turnover | 日均换手率 | 越低越好，<20%较优 |
| Max Drawdown | 最大回撤 | 越小越好 |
| 胜率 | 多头组合跑赢基准的比例 | >55%有意义 |

## 四、因子组合策略

### 低相关性组合
选择 IC 均为正、且两两相关性低的因子等权组合：
- 量价因子 + 动量因子 + 波动率因子 → 三类因子相关性通常较低
- 相关性阈值：|corr| < 0.3 视为低相关

### 复合因子构建
```
复合因子 = w1 * 因子1 + w2 * 因子2 + ... + wn * 因子n
```
权重可按 IC_IR 加权：w_i = IC_IR_i / Σ(IC_IR_i)

## 五、过拟合防范

1. **样本内外分割**：回测数据分训练集/测试集，不在测试集上调参
2. **参数稳健性**：同一逻辑下不同参数（如5日/10日/20日）结果应一致
3. **经济逻辑**：因子必须有可解释的市场逻辑，不搞纯数据挖掘
4. **换手率约束**：过高换手率的因子即使回测好也可能实盘失效
5. **多市场验证**：能在不同市场/不同时期都有效的因子更可靠
